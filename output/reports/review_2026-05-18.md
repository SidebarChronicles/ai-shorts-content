# Pre-/morning Codebase Review — 2026-05-18

Six ECC reviewers (architect, python-reviewer, typescript-reviewer, security-reviewer, silent-failure-hunter, tdd-guide) ran in parallel against the autonomous YouTube Shorts pipeline. This is the aggregated, deduplicated findings list with severity tags and the apply-tonight plan.

## Headline risks

These would most likely cause tomorrow's autonomous `/morning` to ship a broken upload or burn money silently:

1. **`make_audio_elevenlabs.py:619`** — `except Exception: pass` on ffprobe duration check. A zero-byte or truncated MP3 ships as a "successful" narration. `[CRITICAL]`
2. **`render_story.py:439`** — `--from-step N > 3` skips the ElevenLabs budget guard entirely on resume. Re-rendering after a crash can blow the monthly cap. `[CRITICAL]`
3. **`render_story.py:186-194`** — `build_sound_design` `CalledProcessError` is caught with a warning and pipeline continues. Final video can ship with silent ambient. `[CRITICAL]`
4. **`cross_post_status.py:84-87`** — `JSONDecodeError` returns `{}`, so a corrupt state file silently erases all cross-post history on the next write. `[CRITICAL]`
5. **`.claude/commands/morning.md:19`** — `morning_cleanup.py` invoked without `--apply`, so Step 0 is a no-op. Stale `.part` files and EL temp dirs never get pruned. `[CRITICAL — functional regression]`
6. **`build_visuals_track.py:369, 411`** — `sys.exit()` inside library helpers terminates the whole batch process instead of raising. One bad Pika normalize kills the rest of the batch. `[CRITICAL]`

## Conclusion

Security posture is sound (no shell-injection, no eval/pickle, hardened env loader, secrets gitignored). The codebase's real exposure is **silent failure modes**, not vulnerabilities. The 6 CRITICAL items above all share the same pattern: an external integration (FFmpeg / ElevenLabs / Freesound / PostFast / Replicate) fails, the code catches it, prints a warning, and continues with degraded output. The fix is uniform: narrow exception types + fail loudly on the degraded path.
