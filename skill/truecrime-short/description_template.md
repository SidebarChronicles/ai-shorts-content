# Description Template — TrueCrime Shorts (NO external links)

Use this shape for the YouTube description on every case. **No clickable URLs** — the channel doesn't have external linking enabled yet. Cite sources by name + date in plain text instead.

---

## Title format

```
{Hook line — ends with #shorts}
```

Examples:
- `When Hackers Couldn't Steal Your Crypto, They Sent Him #shorts`
- `The Negotiator Was Working For The Hackers #shorts`
- `He Pleaded Guilty. Then He Cut Off His Ankle Monitor. #shorts`

## Description structure

```
{HOOK LINE — single sentence, 80 chars or under, restates the most compelling fact}

{2-3 paragraph case summary — same facts as the script, in slightly more detail. Names searchable keywords (defendant name, case identifier, locations). This is the SEO body — gets indexed.}

📂 Case {case number} — {case caption like "United States v. Smith"}
🏛 {Court name}
⚖ {Judge name}, presiding

📰 Source: {Department/Agency} press release, {Month Day, Year}

⚠ Synthetic narration disclosure: This video uses AI-generated voice narration. Every factual claim is sourced directly from the referenced {Department} press release — no embellishment, no speculation, no naming of uncharged co-conspirators.

New here? This channel publishes one short, fact-checked true-crime case each week, pulled straight from federal court records and DOJ press releases.

#truecrime #shorts {3-5 case-specific niche hashtags} {1-2 broad tags}
```

## Hashtag policy

- **8 hashtags max** — first one is the niche identifier YouTube treats specially (always #truecrime)
- **Always include**: `#truecrime` `#shorts`
- **Case-specific tags**: pick 4-5 of the most relevant
  - For fraud cases: `#fraud` `#federalcrime` `#whitecollarcrime`
  - For crypto cases: `#crypto` `#cryptoheist` `#cybercrime`
  - For violent cases: `#crimestories` `#truecrimecommunity`
  - For healthcare fraud: `#healthcarefraud` `#medicare`
  - For ransomware: `#ransomware` `#cybercrime` `#hacking`
- **Avoid**: `#fyp` `#foryou` (TikTok-isms, don't help on YouTube), `#viral` `#trending` (look spammy)

## Why no URLs

- The YouTube Partner Program requires monetization (4000 watch hours + 1000 subs) before external links are enabled in descriptions
- Until then, every URL in a description either gets ignored by viewers or risks looking spammy
- Plain-text source attribution ("Source: U.S. Department of Justice press release, May 6, 2026") accomplishes the trust/transparency goal without the broken-link feel

When the channel monetizes, swap the plain-text source line for a clickable URL.
