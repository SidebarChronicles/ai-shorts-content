1. Open YouTube Studio → Content
2. For each video above, hover the title → click the pencil edit icon
3. Paste the rewrite from the ✅ line
4. Save
5. Repeat for the next video

**Don't change titles on the same video more than once per week** — YouTube tracks title-edit frequency as a churn signal.

**Measure the impact**: in 72h, run `python3 scripts/analyze_performance.py --game` and compare CTR / avg view % before vs after. If the new titles outperform by ≥10%, that's the new baseline; apply the same formulas to all future videos via the SKILL.md content-decision step.

## What about the description bodies?

Description bodies don't affect CTR but DO affect:
- SEO discoverability (keyword presence)
- Algorithmic categorization (which "neighborhood" the algorithm shows the video in)
- Future-self readability (so we know what each video is about)

Current descriptions are fine. **Don't churn them.** Only update if you're adding affiliate links once those approve.
